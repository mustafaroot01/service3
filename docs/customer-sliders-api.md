# السلايدرات (البانرات) — واجهة تطبيق الزبون

> نقطة واحدة تُرجِع بانرات الصفحة الرئيسية، كل بانر صورة مع **رابط اختياري يُفتح عند الضغط**.
>
> الأساس: `https://servix.diyala.org/api/v1`

---

## `GET /customer/sliders`

يُرجِع البانرات **المفعّلة فقط**، مرتّبة حسب ترتيب العرض ثم المعرّف. **عامّة — بلا توكن.**

**الرأس:** `Accept: application/json`

---

## الرد `200`

```json
{
  "success": true,
  "message": "Sliders retrieved successfully",
  "data": [
    {
      "id": 1,
      "image": "https://servix.diyala.org/storage/sliders/kUUGNzJNagGwm1IzfXhiEbUBWOTZZUkpuKzb66RZ.png",
      "link": null
    },
    {
      "id": 2,
      "image": "https://servix.diyala.org/storage/sliders/9fXbA2c7mQ0dLpVrE8sT1yWuKzN4hJ6oGqRsBnMv.png",
      "link": "https://servix.diyala.org/offers/summer"
    }
  ]
}
```

> العنصر الأول أعلاه من بياناتك الفعلية (`link: null`). الثاني مثال لبانر عليه رابط ضغطة.

---

## حقول العنصر

| الحقل | النوع | الوصف |
|---|---|---|
| `id` | رقم | معرّف البانر. |
| `image` | نص (رابط) | رابط صورة البانر — **دائماً موجود**. اعرضه بنسبة عرضه. |
| `link` | نص \| `null` | **رابط الضغطة**. `null` = البانر للعرض فقط بلا فعل عند الضغط؛ نص = افتحه عند الضغط. |

---

## التعامل مع `link` (مهم)

`link` **قد يكون `null`** لكل بانر، فتعامل معه دائماً:

| قيمة `link` | ماذا يفعل التطبيق عند الضغط |
|---|---|
| `null` | لا شيء — البانر عرض فقط (لا تجعله قابلاً للنقر). |
| رابط (`https://…`) | افتحه (متصفّح داخلي / خارجي حسب تصميمك). |

مثال منطق:

```txt
if (slider.link == null) → اعرض الصورة بلا ضغطة
else                     → عند الضغط افتح slider.link
```

---

## ملاحظات للتطبيق

- **الترتيب محفوظ:** اعرض البانرات بنفس ترتيب `data` (مرتّبة أصلاً من الخادم).
- البانرات المخفيّة (غير المفعّلة) لا تظهر إطلاقاً بالرد — لا تحتاج تصفية من طرفك.
- لو `data` فارغة (`[]`) فلا بانرات مفعّلة حالياً — أخفِ السلايدر كلياً.
- الصورة قد تكون بأي نسبة؛ استعمل حاوية بنسبة ثابتة مع `cover`/`contain` حسب تصميمك.
