# Hoame Service — منصّة خدمات منزلية

نظام متكامل لخدمات المنازل في العراق: **لوحة تحكم** للإدارة و**واجهة API** لتطبيق الزبون، بمشروع واحد يُرفع على سيرفر واحد.

## التقنيات

| الطبقة | التقنية |
|---|---|
| الخلفية | Laravel 12 · PHP 8.3 · MySQL |
| المصادقة | Sanctum بحارسين (`admin` · `user`) |
| الصلاحيات | Spatie Permission — 60 صلاحية · 3 أدوار |
| الواجهة | Vue 3 · TypeScript · Vuetify 3 (قالب Vuexy) |
| البناء | Vite 7 — Laravel يخدم الواجهة المبنية |
| الاختبارات | Pest 3 |

## الوحدات

**اللوحة** — المحافظات والأقضية · الأقسام والخدمات · الاختصاصات · السلايدرات · المدوّنة · الصفحات القانونية · الفنيون · استمارات انضمام الفنيين · الزبائن · الطلبات · لوحة الإحصائيات · المشرفون والأدوار والصلاحيات · الإعدادات.

**تطبيق الزبون** — تصفّح بلا حساب · تسجيل بتوثيق واتساب · طلب خدمة بصور وموقع · متابعة الطلب · الإشعارات · استمارة انضمام الفنيين · طلب حذف الحساب.

## دورة حالة الطلب

```
معلّق ← مؤكّد ← تم تعيين فني ← تم الكشف ← تم إنجاز الخدمة
   └── ملغى (من الزبون وهو معلّق فقط)
```

تغيير الحالة حصراً من الأدمن · تعيين الفني مقيّد بمحافظة الطلب · كل انتقال يُسجَّل مع منفّذه ووقته.

## التشغيل محلياً

```bash
composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan storage:link

php artisan serve          # الخلفية
npm run dev                # الواجهة
```

## النشر

```bash
composer install --no-dev --optimize-autoloader
npm ci && npm run build
php artisan migrate --force
php artisan config:cache && php artisan route:cache
php artisan storage:link
```

**شرطان لا يعمل النظام بدونهما:**

1. **عامل الطابور** — الإشعارات مصفوفة، فبدون عامل دائم لا يُرسل أي إشعار:
   ```bash
   php artisan queue:work --tries=3
   ```
   شغّله تحت `supervisor` أو `systemd`.

2. **مفاتيح الخدمات** — من صفحة الإعدادات باللوحة: رابط ومفتاح **أرقم** (رموز واتساب)، ومفاتيح **OneSignal** (إشعارات الجوال). المفاتيح تُخزَّن مشفّرة بقاعدة البيانات، لا في الملفات.

وحدّث `APP_URL` للدومين الحقيقي — روابط الصور تُبنى منه.
